# Вечный покой 6.0

Текстовая браузерная игра про смотрителя кладбища: копай могилы, вскрывай тела,
крафти свечи, торгуй с деревней и держи репутацию до образцовой (100⭐).

> **Статус: проект сырой.** Ядро и петля геймплея работают, но часть баланса
> (цены, веса дропов, имена покойников) — временные заглушки. Экран леса —
> заглушка. Возможны шероховатости в текстах и интерфейсе.

## Как запустить

Игра собрана на ES-модулях и не требует сборки или зависимостей:

- **GitHub Pages** — просто включите Pages (Settings → Pages → Branch: main / root).
- **Локально** — только через сервер: `python -m http.server` в папке проекта,
  затем откройте `http://localhost:8000`. Двойной клик по `index.html` модули
  не поднимет (ограничение браузеров на `file://`).

## Что уже работает

- Полный дневной цикл: утренние события → действия по энергии → сон.
- Копка могил, морг со вскрытием, клумба, крафт (9 рецептов).
- Похороны с декором и качеством, репутация и епархия.
- Рынок с дрейфующими ценами, торговец Густав, ворон с заказами.
- Церковь: пожертвования и проповеди.
- Технологии за науку, 12 достижений, победа на 100 репутации.
- Автосохранение (localStorage) с миграцией старых сейвов.

## Структура проекта

```
index.html          точка входа
package.json        type: module, зависимостей нет
css/style.css
js/
  main.js           загрузка, реестр действий, вкладки
  core/             шина событий, ГСЧ, состояние, сохранение
  data/             предметы, цены, технологии, тексты, события
  systems/          кладбище, морг, крафт, похороны, экономика...
  screens/          вёрстка экранов
  ui/               роутер, рендер, диалоги
```

Логика отделена от интерфейса: системы ничего не знают про DOM, экраны —
про баланс. Новый контент добавляется в основном файлами из `js/data/`.
